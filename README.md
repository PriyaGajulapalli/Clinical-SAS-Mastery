# Clinical SAS Programming Portfolio

An industry-aligned Clinical SAS learning portfolio built with SAS-provided sample datasets and synthetic clinical-trial data.

This repository documents my structured preparation for an entry-level Clinical SAS Programmer role through hands-on SAS programming practice, clinical data projects, technical documentation, quality-control workflows, SAS log review, debugging, and output validation.

## Career Objective

My goal is to build job-ready skills for an entry-level Clinical SAS Programmer or related clinical data role through structured Base SAS, clinical programming, quality control, technical communication, and interview preparation.

This portfolio demonstrates truthful learning progress and practical evidence. It does not claim professional experience that I have not yet gained.

- Maintain clear and reproducible file names
