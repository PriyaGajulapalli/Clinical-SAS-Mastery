A complete, industry‑aligned portfolio documenting my journey from beginner to job‑ready **Clinical SAS Programmer**.

---

## 🎯 Purpose  
To build strong SAS programming skills, master CDISC standards, understand clinical trial data, and create a professional portfolio demonstrating hands‑on experience for clinical SAS roles.

---

## 🧪 How I Practice  
I follow a structured workflow for every concept:

1. Learn the theory  
2. Write SAS code in **SAS OnDemand (ODA SAS Studio)**  
3. Review the **Log Window** for errors, warnings, and notes  
4. Review the **Output Window** for tables, listings, and figures  
5. Download the `.sas` file  
6. Upload it to the correct folder in this repository  

This ensures deep understanding and real‑world readiness.
