# Base SAS Programs

This folder contains foundational SAS programs and tasks that demonstrate core concepts used in clinical trial programming.

## Topics Covered
- SAS Computing Architecture
- DATA vs PROC Step Boundaries
- WORK vs Permanent Libraries
- Data Ingestion (DATALINES, INFILE)
- File Handling (DLM, DSD, MISSOVER, TRUNCOVER)
- PROC IMPORT / EXPORT
- Log Diagnostics
- Clinical Data Ingestion Tasks
